# Berry-phase polarization paths

For each of the five SQS cells, the relaxed P+ and P- structures were linearly
interpolated using 31 intermediate structures, giving 33 images numbered
`00` through `32`. Berry-phase polarization was evaluated without further
ionic relaxation. The continuous branch was selected so that the change
between neighboring images remained below one half of the polarization
quantum and the path passed through zero at its midpoint.

Each image contains its exact fixed structure, inputs, compact electronic
record, and compressed `OUTCAR`.
