# Fixed-cell NEB calculations

Each path contains the P+ endpoint (`00`), three intermediate images
(`01`--`03`), and the P- endpoint (`04`). Lattice vectors were fixed along
each path. The main-text mean and standard deviation use SQS01, SQS03, SQS04,
and SQS05. Their individual maximum barriers relative to P+ are 12.141,
6.895, 6.074, and 15.841 meV per formula unit, respectively.

SQS02 is included because it is shown and discussed individually in the SI.
Its archived intermediates are the explicitly retained converged `SPRING=0`
state. Image 01 lies 0.405 meV per formula unit below P+, so this path was not
included in the four-SQS main-text average and requires denser/variable-cell
sampling to resolve its fine structure.
